Primera versión de **Janus**: interceptor de tráfico HTTP/HTTPS para pentesting y bug bounty, con motor mitmproxy y app de escritorio nativa.

![Janus](https://raw.githubusercontent.com/facundogomezuy/Janus/main/docs/screenshots/janus-history.png)

| Archivo | Para |
| --- | --- |
| `Janus_0.1.0_x64-setup.exe` | **Windows 10/11 (64 bits).** Se instala para tu usuario, sin permisos de administrador. |
| `Janus_0.1.0_amd64.deb` | Debian / Ubuntu. |

## Instalar en Windows

1. Ejecutá `Janus_0.1.0_x64-setup.exe`. El instalador todavía no está firmado: si aparece *"Windows protegió su PC"*, elegí **Más información → Ejecutar de todas formas**.
2. Abrí Janus y andá a **Setup**:
   - **Abrir navegador Janus**: un perfil aislado de Chrome/Edge/Brave con el proxy y el certificado ya configurados. No toca tu navegador de siempre.
   - **Instalar en Windows** (la CA): para que cualquier app confíe en Janus. Se instala solo para tu usuario; Windows pide confirmación.

En Windows 10 sin WebView2, el instalador lo descarga solo. Windows 11 ya lo trae.

## Qué incluye

- **History**: todo el tráfico en vivo, guardado en SQLite. Filtros (`method:POST status:4xx -cdn`), búsqueda en headers y cuerpos, colores, comentarios, visor Pretty / Raw / Hex y copiar como curl.
- **Intercept**: retiene requests y/o responses para editarlos antes de que sigan: Forward (`Ctrl+Enter`) o Drop. Admite filtros con la sintaxis de mitmproxy.
- **Repeater**: pestañas persistentes que mandan los bytes tal cual (sirve para requests malformados), con Content-Length automático opcional.
- **Scope**: reglas include/exclude (`*.target.com`, `host:8443`, `target.com/api/*`). Lo excluido ni se descifra, ideal para apps con certificate pinning.
- **Setup**: navegador Janus, CA en el almacén de Windows, proxy del sistema (con backup y restauración automática) y guía para otras apps y celulares.
- Tema oscuro y claro, atajos de teclado (`Ctrl+1…5`, `Ctrl+I`, `Ctrl+R`, `Ctrl+T`/`Ctrl+W`) y una sola instancia por usuario.

## Datos y desinstalación

- Tus datos (historial, CA, perfiles del navegador Janus, logs) quedan en `%LOCALAPPDATA%\io.janus.app`. El programa se instala aparte, en `%LOCALAPPDATA%\Janus`.
- Al desinstalar podés marcar *"borrar datos de la aplicación"*. Si instalaste la CA, quitala antes desde **Setup → Quitar de Windows**.

## Seguridad

La API de control escucha solo en `127.0.0.1`, en un puerto aleatorio y con un token de sesión. El proxy escucha en `127.0.0.1:8080` salvo que elijas *Toda la red* en Ajustes.
